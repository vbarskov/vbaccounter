# Журнал реализации

- Подготовлен отдельный репозиторий плагина; исходный VB Accounting оставлен без изменений.
- Чистые модули календаря, отчётности, БНС/Нацбанка и напоминаний перенесены снимком, чтобы работать без Electron и сборки приложения.
- Добавлены stdio MCP, проверяемые схемы инструментов и локальное постоянное состояние с отдельными подтверждениями.
- Добавлены навыки настройки, проверки обязательств и сохранения состояний; расписание остаётся отдельным явным действием пользователя.
- Иконка приложения скопирована без изменений в `assets/icon.png`.
- Добавлены переносимый и совместимый манифесты и локальный marketplace.
- Проверка выявила исчезновение незавершённых месячных задач, неполную проверку назначения БНС и конфликт старого подтверждения с новым отказом; сценарии исправлены и включены в проверки ядра.
- Добавлены исправление локального профиля, сохранение основания применимости и чтение истории уведомлений из нового чата.
- Проверки сначала зафиксировали отсутствие реализации, затем проверяют пользовательские сценарии на временных данных. Итог выполнения указан при передаче пользователю.
- Итог: `node --test tests/*.test.mjs` — 17 тестов прошли. Проверены MCP, манифесты, доказательства, история уведомлений, смена месяца/квартала, конфликты источника и параллельные записи.
- Добавлен слой DeepSeek Harness: `dsh.bundle.patch`, точка входа `dsh/lib/index.js` с bundled-провайдерами навыков и `dsh/install-mcp.mjs`, идемпотентно дописывающий stdio MCP в `cordis.patch.yml` профиля.
- Навыки переименованы в `vb-setup`, `vb-obligations`, `vb-reporting`: DSH хранит навыки всех плагинов в одном реестре, и имя `setup` конфликтовало с уже установленным плагином MCU iOS Git Flow.
- Версия MCP-сервера читается из `package.json`, чтобы манифесты и `serverInfo` не расходились; версия пакета — 0.2.0.
- Проверено: `node --test tests/*.test.mjs` — 24 теста прошли, включая импорт пакета по имени из временного `node_modules`, метаданные трёх навыков и идемпотентность `install-mcp.mjs`.
- Плагин установлен в живой профиль `desktop` командой `dsh plugin add link:`: навыки `vb-setup`, `vb-obligations`, `vb-reporting` появились в каталоге сессии, инструменты `vb_*` подключились без перезапуска, `vb_status` вернул локальный реестр.
- Интерфейс сведён в основной пакет: host-часть регистрирует навыки и read-only маршрут `GET /vbaccounter/status` (маршрут — только если в композиции есть веб-сервер), клиентская половина `./client` рисует чип, панель статусов и карточку в ленте чата. Отдельный пакет `vbaccounter-ui` удалён.
- Клиентская половина проверена без браузера: бандл загружается в Node со заглушками `window.__ModuleLoader__`, React и `react-dom`, регистрация слотов и подписи проверяются тестами; панель рендерится через portal в `document.body`, чтобы шапка чата её не обрезала.
- Итог после слияния: `node --test tests/*.test.mjs` — 28 тестов прошли.
